# BoostBank : application de bureau

Ce dépôt ne contient que les fichiers d'installation de l'application de bureau BoostBank (Windows, macOS, Linux), publiés dans ses [versions](https://github.com/Absolute11111/boostbank-telechargements/releases).

**Téléchargez et installez BoostBank depuis la page officielle : https://boost-bank.vercel.app/telecharger**

Elle explique l'installation pas à pas, pourquoi Windows ou macOS peuvent afficher un avertissement, et comment vérifier l'empreinte SHA-256 de votre fichier (liste `SHA256SUMS` jointe à chaque version).

N'installez jamais un fichier BoostBank reçu par e-mail ou par message.
